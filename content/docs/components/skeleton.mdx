## Usage

```tsx
import { Skeleton } from "higgyui";

export function Example() {
  return (
    <div className="grid gap-2">
      <Skeleton className="max-w-48" />
      <Skeleton className="max-w-32" />
    </div>
  );
}
```

## Props

| Prop | Type | Details |
| --- | --- | --- |
| `animated` | `boolean` | Pulses unless reduced motion is preferred. Defaults to true. |
| `className` | `string` | Set a size that matches the expected content. |

Skeleton is hidden from assistive technology. If the wait matters, communicate loading in the surrounding UI.
