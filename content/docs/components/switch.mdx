## Usage

```tsx
import { Switch } from "higgyui";

export function Example() {
  return (
    <Switch label="Weekly summary" name="summary" description="Receive a recap of workspace activity." defaultChecked />
  );
}
```

## Props

| Prop | Type | Details |
| --- | --- | --- |
| `label` | `string` | Visible switch label. Required. |
| `description` | `string` | Supporting text connected to the switch. |
| `Native input props` | `ComponentProps` | Supports name, checked, defaultChecked, onChange, and disabled. className applies to the wrapper. |
