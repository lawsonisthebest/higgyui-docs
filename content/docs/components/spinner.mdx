## Usage

```tsx
import { Spinner } from "higgyui";

export function Example() {
  return (
    <Spinner label="Loading projects" size={24} />
  );
}
```

## Props

| Prop | Type | Details |
| --- | --- | --- |
| `label` | `string` | Status text for assistive technology. Defaults to Loading. |
| `size` | `number` | Icon size in pixels. Defaults to 19. |
