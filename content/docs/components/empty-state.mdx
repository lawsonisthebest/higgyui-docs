<ComponentPreview name="empty-state" />

## Usage

```tsx
import { EmptyState } from "higgyui";
import { Folder } from "lucide-react";

export function Example() {
  return (
    <EmptyState title="No projects yet" icon={Folder}
      description="Projects you create will show up here."
    />
  );
}
```

## Props

| Prop | Type | Details |
| --- | --- | --- |
| `title` | `ReactNode` | Visible heading. Required. |
| `description / action` | `ReactNode` | Supporting text and an optional action element. |
| `icon` | `LucideIcon` | Optional icon component. |
