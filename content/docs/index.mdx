HiggyUI gives React apps a set of components with white surfaces, neutral borders, rounded corners, and thin Lucide icons. Use them individually or combine them to build a form, settings screen, or workspace.

## A first component

Once HiggyUI and its stylesheet are installed, import components by name.

```tsx
import { Button, Card } from "higgyui";

export function ProjectSummary() {
  return (
    <Card title="Project summary" description="A workspace for your team.">
      <Button title="View project" hoverAnimation />
    </Card>
  );
}
```

Most form controls accept standard React DOM props such as `name`, `required`, and `disabled`. Each component page explains its additional settings.
